# CLI Type Generator (`appwrite-react-gen`)

The `appwrite-react-gen` CLI tool connects to your Appwrite backend using a Server API Key, inspects all database collections and attributes, and automatically outputs type-safe TypeScript interfaces.

---

## 🛠️ Usage

Run via `npx` in your project terminal:

```bash
npx appwrite-react-gen \
  --endpoint=https://cloud.appwrite.io/v1 \
  --project=PROJECT_ID \
  --key=SERVER_API_KEY \
  --db=DATABASE_ID \
  --out=src/types/appwrite.d.ts
```

---

## ⚙️ CLI Options & Environment Variables

| Flag | Environment Variable | Required | Description |
|---|---|---|---|
| `--endpoint` | `APPWRITE_ENDPOINT` | **Yes** | Appwrite API endpoint URL. |
| `--project` | `APPWRITE_PROJECT_ID` | **Yes** | Appwrite Project ID. |
| `--key` | `APPWRITE_API_KEY` | **Yes** | Appwrite Server API Key (requires Database read scope). |
| `--db` | `APPWRITE_DATABASE_ID` | **Yes** | Appwrite Database ID. |
| `--out` | `APPWRITE_OUT_FILE` | No | Output TypeScript declaration file path (default: `src/types/appwrite.d.ts`). |

## 📄 Example Generated TypeScript Output

```typescript
/**
 * Auto-generated by @repo/react-appwrite CLI (appwrite-react-gen)
 * Database ID: main_db
 */

import type { Models } from "appwrite";

// ==========================================
// Collection: Posts (posts_coll)
// ==========================================
export interface Posts {
  title: string;
  price: number;
  status: "active" | "draft" | "archived";
  tags?: string[];
  authorId: string;
}

export type PostsDocument = Posts & Models.Document;

export interface MainDbDatabaseCollections {
  "posts_coll": PostsDocument;
}
```

## 💡 How to Use in Your Components

Once generated, pass the interface directly to `useCollection`, `useDocument`, or `useMutations`:

```tsx
import { useCollection } from "@repo/react-appwrite";
import type { Posts } from "../types/appwrite";

export function PostsFeed() {
  const { documents, setSearch, setFilter } = useCollection<Posts>("main_db", "posts_coll", {
    where: {
      status: "active", // Autocompleted & Type-Safe!
      price: { $gte: 100 },
    },
    sortField: "price", // Autocompleted & Type-Safe!
  });

  return (
    <div>
      {documents.map((post) => (
        <h2 key={post.$id}>{post.title} - ${post.price}</h2>
      ))}
    </div>
  );
}
```
